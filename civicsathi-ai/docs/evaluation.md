# Evaluation plan

No model quality scores are claimed by this starter scaffold. Before reporting results, prepare a labeled test set and evaluate:

- Service/category classification accuracy and confusion matrix.
- Field-level precision and recall for structured extraction.
- Precision/recall for possible-duplicate suggestions, with false-positive review.
- Separate results for English, Hindi, and Punjabi.
- Task completion and user feedback in usability testing.
- Harness behavior for malformed output, model unavailable, and denied actions.

Document dataset size, data source, labeling method, model name/version, parameters, hardware and failures. Use synthetic or public-safe examples until privacy and permission requirements are settled.
